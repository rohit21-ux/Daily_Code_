# Programming Example 2:

Problem : Find smallest number in a list

Algorithm :

1. Assume first number is smallest
2. Compare with next number
3. If smaller found -> update smallest
4. Repeat untill end
5. Return smallest

# code: 

def find_min(arr):
    min_val =  arr[0]
    for num in arr:
        if num < min_val:
           min_val = num
    return min_val
